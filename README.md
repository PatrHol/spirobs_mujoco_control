# spirobs_mujoco_control

Управление кончиком гибкого спирального робота (Spirobs) в симуляторе MuJoCo.

## Что делает

Скрипт `ik_control.py`:

1. Загружает XML-модель Spirobs (сгенерированную в
   [Open-Spiral-Robots-v1](https://github.com/EstelleStar8/Open-Spiral-Robots-v1)).
2. Автоматически определяет структуру модели:
   - число hinge-суставов,
   - кончик (последнее тело без детей),
   - базу (первое тело),
   - плоскость движения (по оси вращения суставов),
   - ограничения углов (из `jnt_range`).
3. Реализует **прямую кинематику (FK)** через `mujoco.mj_kinematics`.
4. Реализует **обратную кинематику (IK)** методом демпфированных
   наименьших квадратов (DLS) с численным Якобианом.
5. Строит **рабочую зону** (случайная выборка конфигураций).
6. Спрашивает у пользователя целевую точку в плоскости **YZ**
   (или принимает через `--target`).
7. Проверяет достижимость точки — выводит «НЕДОСТИЖИМО», если
   ошибка IK превышает порог.
8. Открывает MuJoCo viewer и удерживает робота в достигнутой позе.
   Целевая точка отображается красной полупрозрачной сферой.

## Установка

Требуется Python 3.10+ и MuJoCo.

```bash
pip install mujoco numpy
```

## Использование

### Интерактивно

```bash
python ik_control.py
```

Скрипт спросит Y и Z, покажет рабочую зону и пример точки.

### С явной целью

```bash
python ik_control.py --target 0.15 0.70
```

### С явным XML

```bash
python ik_control.py --xml path/to/robot.xml
```

### Полный список аргументов

```bash
python ik_control.py --help
```

| Аргумент | Описание |
|----------|----------|
| `--xml PATH` | Путь к XML. Если не указан — ищет последний в `exports/xml_*/`. |
| `--target Y Z` | Целевая точка (м). Пропускает интерактивный ввод. |
| `--samples N` | Число сэмплов для оценки рабочей зоны (по умолчанию 3000). |
| `--tol-mm MM` | Порог достижимости в мм (по умолчанию 5.0). |

## Как это работает

### Прямая кинематика (FK)

Каждый сегмент — hinge-сустав вокруг оси X. Положение кончика
вычисляется MuJoCo через `mj_kinematics` — это быстро и точно.

### Обратная кинематика (IK)

Задача: найти углы `q` такие, что `FK(q) = (y*, z*)`.

Используется **демпфированный метод наименьших квадратов**:

```
dq = Jᵀ (J Jᵀ + λ I)⁻¹ · error
```

где:
- `J` — численный Якобиан 2×N,
- `λ` — коэффициент демпфирования (1e-3),
- `error = (y* - y, z* - z)`.

Метод устойчив для избыточных систем (у нас 23 сустава, а задача 2D).

### Ограничения

- Углы ограничены `q_min..q_max` (из XML, обычно ±30°).
- Шаг за итерацию ограничен (`max_step = 0.1`), чтобы избежать
  «прыжков» через минимум.
- Точка считается **недостижимой**, если ошибка IK > `--tol-mm`.
